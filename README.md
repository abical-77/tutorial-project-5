## 🚀 طرق عرض الموقع

### **الطريقة الأولى: عرض مباشر من الإنترنت (الأسهل)**
- ما عليك سوى فتح الرابط أعلاه في متصفحك
- الموقع يعمل بشكل كامل والصور تظهر تلقائياً
- لا تحتاج لأي برامج إضافية

### **الطريقة الثانية: عرض محلي من جهازك**

#### على Windows:
1. فك الضغط عن ملف `godfather_final_v2.zip`
2. افتح `Command Prompt` أو `PowerShell`
3. انتقل إلى مجلد المشروع:
   ```
   cd C:\path\to\godfather_project
   ```
4. شغل خادم ويب:
   ```
   python -m http.server 8000
   ```
5. افتح متصفحك واذهب إلى: `http://localhost:8000`

#### على Mac/Linux:
1. فك الضغط عن ملف `godfather_final_v2.zip`
2. افتح Terminal
3. انتقل إلى مجلد المشروع:
   ```
   cd /path/to/godfather_project
   ```
4. شغل خادم ويب:
   ```
   python3 -m http.server 8000
   ```
5. افتح متصفحك واذهب إلى: `http://localhost:8000`

#### الطريقة الأبسط: فتح الملف مباشرة
- يمكنك ببساطة فتح ملف `index.html` بالنقر المزدوج عليه
- سيفتح الموقع في متصفحك الافتراضي
- **ملاحظة:** قد لا تظهر الصور إذا فتحت الملف بهذه الطريقة من جهازك، لكن الرابط المباشر أعلاه يضمن ظهور كل شيء

## 💾 ملفات المشروع

### `index.html`
- يحتوي على البنية الأساسية للصفحة
- جميع الصور مرتبطة برابط مباشر
- يستدعي ملف `styles.css` للتصميم

- جميع تنسيقات الألوان والتخطيطات

- يحتوي على نسخ أصلية من الصور
- للاستخدام المحلي أو المشاريع المستقبلية
